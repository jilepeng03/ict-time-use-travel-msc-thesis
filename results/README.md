# Results

This folder is reserved for selected outputs that are suitable for public sharing, such as final figures or compact summary tables.

The full analysis writes reproducible generated outputs to:

```text
combined_outputs_harmonised/
```

That generated directory is excluded from version control by default. No dissertation results are duplicated here in the initial repository because the source output files were not supplied as part of the GitHub-preparation step.

Before adding outputs here, check that they contain no restricted microdata or disclosive information.
